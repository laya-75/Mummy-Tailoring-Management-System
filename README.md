# Mummy's Tailoring Management System

A web-based Tailoring Management System designed to help manage a tailoring business easily and efficiently.

## About the Project

Mummy's Tailoring Management System helps manage customer details, tailoring orders, payments, and delivery status in one place. It reduces manual paperwork and makes daily business management easier.

## Features

- **Admin Login** – Secure login for the administrator.
- **Customer Management** – Manage customer information.
- **Order Management** – Add and manage tailoring orders.
- **Payment Tracking** – Keep track of order payments.
- **Order Status** – Track the progress of orders.
- **Online Database** – Store application data using MySQL.

## Database Setup

1. Create a MySQL database.
2. Import the `schema.sql` file into the database.
3. Configure the database connection in `config.php`.
4. Upload the project files to a PHP-supported web hosting service.
